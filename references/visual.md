# 視覺比對審核 (Visual Review)
重點關注：
- **佈局對齊 (Layout & Alignment)**：檢查元素間距 (Margin/Padding)、對齊方式是否與設計稿一致。
- **色彩與字體 (Color & Typography)**：驗證字體大小、磅數 (Weight)、行高 (Line-height) 及顏色代碼。
- **響應式表現 (Responsive Design)**：比對在不同斷點 (Breakpoints) 下的排版變換是否正確。
- **組件還原度 (Component Fidelity)**：檢查按鈕形狀、陰影、圓角 (Border-radius) 等細節。
- **視覺一致性 (Visual Consistency)**：確保翻寫成框架 (如 Vue/React) 後，沒有因為 CSS 權重或組件封裝導致的樣式跑版。
